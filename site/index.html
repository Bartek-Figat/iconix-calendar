CLI

Calendar tools in your terminal

The package installs an iconix-calendar command. It reads .json and .ics files, so you can convert exports, check data in CI or find a free slot from a script. Add --json for machine-readable output.

Terminal
CommandWhat it does

Exit codes: 0 ok, 1 the check found something (a clash, invalid data, no free slot), 2 usage error. Handy for CI.

Compatibility

Where can I use it?

The core is plain ES modules with TypeScript types. Its two runtime dependencies are siblings from the same family: @iconix/icons draws every icon and @iconix/search powers event search (typos, word forms, field queries). React and Vue are optional peer dependencies, used only by their wrappers.
